Color · Light

颜色

整体只有黑白灰，没有品牌强调色，唯一的彩色是完成状态的绿色。色值取自文字笔画最深的像素，细笔画受抗锯齿影响，实际值可能再深 1–3 级。录屏只有浅色模式。点按色块可复制色值。

Typography

字体

使用 iOS 系统字体：中文是苹方（PingFang SC），英文和数字是 SF Pro，不引入自定义字体。字号是用连续汉字的间距量出来的（每个汉字正好 1 个字号宽），17.5、14.5、10.5 这类半磅值是实测结果，不是取整误差。下面的样例按实际字号绘制。
