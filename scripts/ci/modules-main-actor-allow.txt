# @MainActor exceptions for the eight phone-DSH modules.
#
# One entry per line: path | expires | reason
#
# An entry is a recorded debt, not a switch. It only silences the
# "main-actor" findings of that path, it must carry an expiry date, and it
# must say why the main actor is genuinely required. An entry that no longer
# matches a live finding is itself a finding, so this file cannot rot
# silently. The rule it relaxes is in modules.py: the phone runtime modules
# must stay usable off the main actor, because the engine and the controller
# keep working while no view is on screen.
